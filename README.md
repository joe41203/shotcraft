# shotcraft

スクリーンショットを撮影・編集できる Chrome 拡張です（開発中）。[WXT](https://wxt.dev/) + vanilla TypeScript、描画は [Konva](https://konvajs.org/) で構築しています。表示範囲・範囲選択のキャプチャと、撮影結果に注釈を描き込める編集タブを備えています（モザイク・クロップ・書き出しは今後追加予定）。

## セットアップ

```bash
pnpm install
pnpm build
```

`pnpm build` すると `.output/chrome-mv3/` にビルド成果物（MV3 拡張一式）が生成されます。

## ローカルの Chrome に読み込む

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、`.output/chrome-mv3` を選択する

## 使い方

ツールバーの拡張アイコンをクリックしてポップアップを開き、2 つのボタンから選びます。

- 表示範囲をキャプチャ: 現在アクティブなタブの表示領域全体を撮影します。
- 範囲を選択してキャプチャ: ページ上にオーバーレイが表示され、ドラッグで選んだ矩形を撮影します。ドラッグ中は選択領域とサイズ（幅 x 高さ）が表示され、`Esc` でキャンセルできます。

どちらもキャプチャ後に新しいタブでエディタが開き、画像に注釈を描き込めます。撮影データと編集内容は `browser.storage.session`（ブラウザを閉じるまで有効なセッションストレージ）に保存されるため、ディスクには書き出しません。

## エディタ

エディタ上部のツールバーからツール・色・線の太さを選び、画像の上にドラッグやクリックで注釈を描きます。ツールは選択・矢印・矩形・楕円・テキスト・ペン・蛍光マーカーの 7 種類です。

- 描画: 矢印・矩形・楕円はドラッグで描画します。ペンと蛍光マーカーはフリーハンドで、マーカーは太く半透明に描かれます。
- テキスト: テキストツールでクリックした位置に入力欄が開きます。`Enter` で確定、`Shift+Enter` で改行、`Esc` でキャンセルです。図形をダブルクリックすると再編集できます。
- 選択・変形: 選択ツールで図形をクリックすると選択でき、周囲のハンドルで移動・リサイズ・回転できます。
- 色と太さは新しく描く図形に適用されます（既存図形への適用は今後対応）。
- 編集内容は自動保存され、エディタのタブをリロードしても復元されます。

### キーボードショートカット

| キー | 動作 |
| --- | --- |
| `V` | 選択ツール |
| `A` | 矢印ツール |
| `R` | 矩形ツール |
| `E` | 楕円ツール |
| `T` | テキストツール |
| `P` | ペンツール |
| `M` | 蛍光マーカーツール |
| `Delete` / `Backspace` | 選択中の図形を削除 |
| `Esc` | 選択解除（未選択なら選択ツールへ戻る） |
| `0` | 全体フィット表示 |
| `Ctrl`/`Cmd` + `Z` | 元に戻す |
| `Ctrl`/`Cmd` + `Shift` + `Z`（または `Ctrl`/`Cmd` + `Y`） | やり直し |
| `Ctrl`/`Cmd` + ホイール | カーソル位置を中心にズーム |
| ホイール / トラックパッド | パン（スクロール） |

テキストの入力中は上記のツール切り替え・削除などのショートカットは無効になります。

## 権限

- `activeTab`: アクティブなタブの表示領域をキャプチャするために使います。
- `scripting`: 範囲選択オーバーレイをアクティブタブに注入するために使います。
- `storage`: キャプチャ結果をセッションストレージへ一時保存するために使います。

`host_permissions` は要求しません。範囲選択のオーバーレイは、静的な content script ではなく、ボタン操作の時点で `scripting.executeScript` によりアクティブタブへ注入します。

## 既知の制限

- `chrome://` などのブラウザ内部ページ、Chrome ウェブストア、拡張機能の管理ページ、他拡張のページでは、Chrome の制約によりキャプチャ・範囲選択ができません。これらのページで範囲選択を実行しても何も起きず、拡張の Service Worker のコンソールに警告を出して終了します。
- `captureVisibleTab` はブラウザ側で 2 回/秒に制限されます。短時間に連続でキャプチャした場合、超過分は破棄せずスロットが空くまで待ってから実行します。

## 開発

```bash
pnpm dev
```

`pnpm dev` を実行すると、拡張機能を読み込んだ専用プロファイルの Chrome が自動起動し、ソースの変更がホットリロードされます。

## テスト

座標変換（CSS px から画像 px への変換）、エディタのドキュメントモデルと undo/redo 履歴、ズーム/フィット計算のユニットテストを [Vitest](https://vitest.dev/) で用意しています。

```bash
pnpm test
```
