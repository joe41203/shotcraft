# shotcraft

スクリーンショットを撮影・編集できる Chrome 拡張です（開発中）。[WXT](https://wxt.dev/) + vanilla TypeScript、描画は [Konva](https://konvajs.org/) で構築しています。表示範囲・範囲選択のキャプチャと、撮影結果に注釈・モザイク・クロップを施して PNG で書き出せる編集タブを備えています。

## セットアップ

```bash
pnpm install
pnpm build
```

`pnpm build` すると `.output/chrome-mv3/` にビルド成果物（MV3 拡張一式）が生成されます。

## ローカルの Chrome に読み込む

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、`.output/chrome-mv3` を選択する

## 使い方

ツールバーの拡張アイコンをクリックしてポップアップを開き、2 つのボタンから選びます。

- 表示範囲をキャプチャ: 現在アクティブなタブの表示領域全体を撮影します。
- 範囲を選択してキャプチャ: ページ上にオーバーレイが表示され、ドラッグで選んだ矩形を撮影します。ドラッグ中は選択領域とサイズ（幅 x 高さ）が表示され、`Esc` でキャンセルできます。

どちらもキャプチャ後に新しいタブでエディタが開き、画像に注釈を描き込めます。撮影データと編集内容は `browser.storage.session`（ブラウザを閉じるまで有効なセッションストレージ）に保存されるため、ディスクには書き出しません。

## エディタ

エディタ上部のツールバーからツール・色・線の太さを選び、画像の上にドラッグやクリックで注釈を描きます。ツールは選択・矢印・矩形・楕円・テキスト・ペン・蛍光マーカー・モザイク・クロップの 9 種類です。

- 描画: 矢印・矩形・楕円はドラッグで描画します。ペンと蛍光マーカーはフリーハンドで、マーカーは太く半透明に描かれます。
- テキスト: テキストツールでクリックした位置に入力欄が開きます。`Enter` で確定、`Shift+Enter` で改行、`Esc` でキャンセルです。図形をダブルクリックすると再編集できます。
- モザイク: モザイクツール（`X`）でドラッグした矩形範囲をピクセル化して隠します。ピクセルの粗さは範囲の大きさから自動で決まります。選択ツールで移動・リサイズ・削除でき、位置や大きさを変えるとピクセル化はその都度計算し直されます。
- クロップ: クロップツール（`C`）を選ぶと画像の内側にトリミング枠が現れます。枠のハンドルや枠自体をドラッグして範囲を調整し、`Enter` で確定、`Esc` でキャンセルします。確定するとキャンバスはその範囲だけを表示します。もう一度クロップすると現在の範囲をさらに絞り込めます。クロップは元に戻す（`Ctrl`/`Cmd`+`Z`）で解除できます。
- 選択・変形: 選択ツールで図形をクリックすると選択でき、周囲のハンドルで移動・リサイズ・回転できます（モザイクは回転できません）。
- 出力: ツールバー右端の「PNG保存」でクロップ適用後の画像を PNG ファイルとしてダウンロードし、「コピー」（または `Ctrl`/`Cmd`+`C`）でクリップボードへコピーします。出力内容はベース画像・モザイク・注釈を合成したもので、常にキャプチャ原寸です（画面の表示倍率には影響されません）。選択枠やトリミング枠は含まれません。
- 色と太さは新しく描く図形に適用されます（既存図形への適用は今後対応）。
- 編集内容（注釈・モザイク・クロップ）は自動保存され、エディタのタブをリロードしても復元されます。

### キーボードショートカット

| キー | 動作 |
| --- | --- |
| `V` | 選択ツール |
| `A` | 矢印ツール |
| `R` | 矩形ツール |
| `E` | 楕円ツール |
| `T` | テキストツール |
| `P` | ペンツール |
| `M` | 蛍光マーカーツール |
| `X` | モザイクツール |
| `C` | クロップツール |
| `Enter` | クロップ範囲を確定（クロップ操作中） |
| `Delete` / `Backspace` | 選択中の図形を削除 |
| `Esc` | 選択解除／クロップのキャンセル（未選択なら選択ツールへ戻る） |
| `0` | 全体フィット表示 |
| `Ctrl`/`Cmd` + `C` | 画像をクリップボードへコピー |
| `Ctrl`/`Cmd` + `Z` | 元に戻す |
| `Ctrl`/`Cmd` + `Shift` + `Z`（または `Ctrl`/`Cmd` + `Y`） | やり直し |
| `Ctrl`/`Cmd` + ホイール | カーソル位置を中心にズーム |
| ホイール / トラックパッド | パン（スクロール） |

テキストの入力中は上記のツール切り替え・削除などのショートカットは無効になります。

## 権限

- `activeTab`: アクティブなタブの表示領域をキャプチャするために使います。
- `scripting`: 範囲選択オーバーレイをアクティブタブに注入するために使います。
- `storage`: キャプチャ結果をセッションストレージへ一時保存するために使います。

`host_permissions` は要求しません。範囲選択のオーバーレイは、静的な content script ではなく、ボタン操作の時点で `scripting.executeScript` によりアクティブタブへ注入します。

## 既知の制限

- `chrome://` などのブラウザ内部ページ、Chrome ウェブストア、拡張機能の管理ページ、他拡張のページでは、Chrome の制約によりキャプチャ・範囲選択ができません。これらのページで範囲選択を実行しても何も起きず、拡張の Service Worker のコンソールに警告を出して終了します。
- `captureVisibleTab` はブラウザ側で 2 回/秒に制限されます。短時間に連続でキャプチャした場合、超過分は破棄せずスロットが空くまで待ってから実行します。
- モザイクはベース画像（キャプチャ元の画像）だけをピクセル化します。モザイクの下に注釈図形を重ねても、その注釈にはモザイクは掛かりません。注釈を隠したい場合はモザイクを最後（最前面）に置いてください。
- PNG のダウンロードとクリップボードへのコピーは、拡張タブでの操作を起点にするため追加の権限を必要としません（`downloads` やクリップボード書き込みの権限は要求しません）。書き出し形式は PNG のみです。

## 開発

```bash
pnpm dev
```

`pnpm dev` を実行すると、拡張機能を読み込んだ専用プロファイルの Chrome が自動起動し、ソースの変更がホットリロードされます。

## テスト

座標変換（CSS px から画像 px への変換）、エディタのドキュメントモデルと undo/redo 履歴、ズーム/フィット計算、モザイクのピクセルサイズ決定、クロップの座標合成、出力ファイル名の生成のユニットテストを [Vitest](https://vitest.dev/) で用意しています。

```bash
pnpm test
```
